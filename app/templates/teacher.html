{# Краткая шпаргалка внизу дашборда #}
Краткая шпаргалка: как всё работает

Создать тест. Вручную (форма «10 вопросов по полям», проще всего), загрузить готовый JSON или PDF-презентацию → «Сгенерировать вопросы из PDF».

Поправить вопросы. Откройте тест (draft/scheduled) → «✎ Редактировать вопросы» — меняйте тексты, варианты, правильный ответ.

Открыть студентам. Откройте тест → «Открыть доступ». Нужны 10 вопросов.

Открыть по расписанию. Откройте тест → блок «Расписание» → выберите дату/время (МСК) → «Запланировать открытие». Откроется само.

Закрыть тест. Откройте тест → «Закрыть тест». Попытки сохраняются.

Прогресс студентов. Кнопка «Аналитика»: ошибки по сложности + таблица попыток с разбором.

Допуск к зачёту. Кнопка «Допуск»: кто готов ({{ tests_required }} тестов, ≥ {{ correct_required }}/{{ total_questions }} правильных, лучшая попытка). Там же — экспорт в CSV.
