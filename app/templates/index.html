SMM Testing

Сервис тестирования студентов по курсу «Взаимодействие с социальными медиа». Здесь студенты проходят тесты по лекциям и получают зачёт автоматически, а преподаватель управляет тестами и следит за успеваемостью групп.

Студентам

  1. Зарегистрируйтесь в кабинете студента (ФИО, e-mail, группа).
  2. Выберите лекцию из списка открытых тестов ниже.
  3. Пройдите тест: {{ questions_per_test }} вопросов на {{ time_limit_minutes }} минуты.
  4. Зачёт — при ≥ {{ pass_threshold }} правильных. Перепройти можно через 24 часа, засчитывается лучшая попытка.

Преподавателям

  1. Войдите в кабинет преподавателя по секретному ключу.
  2. Создавайте тесты по лекциям — вопросы можно сгенерировать из PDF.
  3. Открывайте тест по расписанию или вручную для нужных групп.
  4. Смотрите аналитику по студентам, группам и лекциям.
